# SNS投稿文制作

`sns-post-writer` エージェントを使用して進める。

1. 対象プロジェクトのREADME、コード、仕様書を調査する。
2. 実装済み機能、独自性、公開URLの有無を確認する。
3. TikTok用とX用の本文を**それぞれ最適化して**作成する。
4. 各媒体で推奨案と別案を提示する。
5. `social-posts/research.md`、`tiktok.md`、`x.md`、`review.md` に記録する。
6. 不明点・未実装機能を事実として扱わず、投稿は行わない。
7. 作業結果は日本語で報告する。

指定がなければ、日本語、TikTokは70〜180文字程度、Xは280文字以内を目安にする。
